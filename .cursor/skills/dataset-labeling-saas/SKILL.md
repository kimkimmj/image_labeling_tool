# 시스템 스킬 컨텍스트

## 1. 이 시스템은 무엇인가

ML 데이터셋 라벨링 SaaS 시스템이다.

담당 영역:
- 이미지/영상 업로드
- YOLO를 이용한 자동 라벨링
- 어노테이션 (바운딩 박스)
- 리뷰 워크플로
- 데이터셋 버전 관리
- YOLO 내보내기 파이프라인

---

## 2. 핵심 워크플로

1. 데이터 업로드 (이미지 zip 또는 영상)
2. YOLO 모델로 자동 라벨링
3. 어노테이터가 바운딩 박스 수정
4. 리뷰 제출
5. 리뷰어가 승인하거나 되돌림
6. 데이터셋 버전 생성 (참조 스냅샷)
7. 데이터셋을 train/val/test로 분할
8. YOLO 형식 데이터셋 내보내기 (zip)

---

## 3. 주요 개념

### 배정
- 이미지 1개 → 어노테이터 1명
- 상태 기반 워크플로

### 어노테이션
- 바운딩 박스만
- 클래스는 프로젝트 클래스여야 함

### 데이터셋 버전
- 참조 기반 스냅샷
- 중복 없음

### 내보내기
- 비동기 작업
- YOLO 형식 데이터셋 생성

---

## 4. 파일 저장

- 모든 미디어는 MinIO 사용
- 이미지/영상은 DB에 중복 저장하지 않음

---

## 5. ML 연동

- YOLO (Ultralytics)
- model_classes는 프로젝트로 가져옴
- 자동 라벨링은 업로드 시점에만 수행

---

## 에이전트 사용 안내

위 내용을 이 저장소의 기준이 되는 제품 컨텍스트로 취급한다. 데이터 모델, API, UX를 제안할 때 사용자가 명시적으로 다르게 요구하지 않는 한, 워크플로·배정 규칙·스냅샷 의미·MinIO 전용 blob·업로드 시점 자동 라벨링 제약과 맞춘다.
